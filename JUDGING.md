# Judge path

- Track: ClickHouse.
- Public web product: <https://safe-frame-regression-109051079423.us-central1.run.app>.
- Google runtime: `/health` performs a real Vertex generation.
- Mandatory partner runtime: `/v1/integrations/clickhouse/evidence` lists and calls the official `mcp-clickhouse` server against the live HTTPS cluster.
- Repository and detected Apache-2.0 licence: <https://github.com/usv240/safe-frame>.
- Public video and final Devpost confirmation remain release actions; they are not represented as complete.

## Four equal judging criteria

| Criterion | Inspect this | What it proves |
|---|---|---|
| Technological Implementation | Run the constructed scan, inspect MCP evidence, then request an explanation | Direct spatial measurement, presentation-time lineage, live SQL anti-join, request-bound ADK evidence, fail-closed behavior |
| Design | Use `/` in Plain mode, then Technical mode | One coherent non-flashing path for an editor and an engineering judge |
| Potential Impact | Compare approved master with the child-only failure | The product addresses the operational gap where a downstream transform invalidates earlier review |
| Quality of Idea | Read `docs/PRIOR-ART.md` | Detection, repair, dimming, and batch scale are conceded; the narrow public gap is lineage regression |

## Ninety-second test

1. Press **Run real ClickHouse proof**.
2. Confirm the parent passes, child fails, and `regression_count` is one.
3. Open MCP evidence and confirm the official tool plus live query.
4. Press **Ask the ADK agent** and confirm `decision_source` remains SQL/MCP and `requires_human` is true.
5. Open `/health`; all four runtime checks should be true.

The sample is constructed engineering evidence. Safe Frame is not a certified device and makes no medical efficacy claim.
